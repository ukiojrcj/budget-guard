BUDGET GUARD — LAST FINAL EDITABLE VERSION

Files:
- index.html
- style.css
- app.js
- manifest.json

What is editable:
1. Starting balance
2. Monthly spending limit
3. Budget month
4. Every spending date
5. Every spending amount
6. Spending category / where the money went
7. Spending note
8. Any saved spending can be edited from the receipt
9. "Clear receipt" deletes all spending entries and starts a fresh receipt while keeping your budget settings

Data:
- Saved in this browser/device using localStorage.
- Uploading the files to GitHub does NOT upload personal spending data.
- Different browsers/devices have separate spending data.

To use:
Open index.html in a browser, or upload the whole folder to GitHub and enable GitHub Pages.
